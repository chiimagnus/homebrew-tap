# Homebrew Tap

```bash
brew install chiimagnus/tap/roamer
brew install chiimagnus/tap/applebookscli
brew install chiimagnus/tap/applemapscli
```

- Roamer installs a precompiled Apple Silicon CLI; using it still requires macOS 26.6+, Xcode 27+, and a visionOS 27+ Apple Vision Pro Simulator.
- AppleBooksCLI installs the latest stable release package on Apple Silicon, macOS 15.6+.
- AppleMapsCLI installs a precompiled Apple Silicon binary for macOS 15.6+.
