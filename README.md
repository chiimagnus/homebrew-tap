# Homebrew Tap

```bash
brew install chiimagnus/tap/roamer
brew install chiimagnus/tap/applebookscli
```

- Roamer requires an Apple Silicon Mac, macOS 26.6+, Xcode 27+, and a visionOS 27+ Apple Vision Pro Simulator.
- AppleBooksCLI installs the latest stable release package, follows its published architectures, and requires macOS 12+.
